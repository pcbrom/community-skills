# Julia skill template (placeholder)

The Julia bridge (`bridges/julia.py`) is not yet implemented. The design
will mirror `bridges/r.py`: spawn `julia` and exchange JSON via stdin/stdout.

If you want to implement it, open an issue tagged `bridge:julia` to align
on the API. Once the bridge lands, this template will receive a
`SKILL.md.template` and an `invoke.jl.template` mirroring the R ones.
